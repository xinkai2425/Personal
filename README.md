# Kai Xin | 校园晴日

辛凯的个人主页。天蓝、淡黄与莓红配色搭配真实自习照片，采用明亮的校园风格。原生 HTML、CSS 和 JavaScript，可直接部署到 GitHub Pages。

## 修改内容

个人简介、学业、课程、技能、项目、荣誉和联系方式统一保存在 `content.js`。`avatar` 指向 `assets/person.jpg`；页面结构在 `index.html`，样式在 `styles.css`，数据渲染和返回顶部交互在 `app.js`。

## 本地预览

直接打开 `index.html`，或运行 `python -m http.server 8000` 并访问本地8000端口。

## 设计记录

采用 A「校园晴日」，确认记录见 `direction-approved.md`。初稿在 `design-demos/`，原版源码备份在 `design-demos/original-v1/`。

## 发布

GitHub Pages 选择从默认分支根目录发布，保留现有 `CNAME` 和 `.nojekyll`。
