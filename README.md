# Open Source Contributor Portfolio

辛凯的开源协作者个人主页，使用原生 HTML、CSS 和 JavaScript 构建，可直接部署到 GitHub Pages。

## 更新内容

所有个人资料、项目和贡献记录都在 `content.js`。添加贡献时使用以下字段：

```js
{
  type: "Pull Request",
  title: "贡献标题",
  summary: "一句话说明贡献产生的价值"
}
```

## 本地预览

直接打开 `index.html`，或在目录中启动任意静态文件服务器。

## 发布

建议仓库名使用 `xky201225.github.io`，将默认分支设为 `main`，并在仓库设置的 Pages 页面选择从 `main` 根目录发布。
